# 已确认范围与剩余问题
版本：v0.8｜2026-11-07

## 已确认
- 内部员工使用、管理员分配账号登录，重点面向非技术人员。
- 产品为智能体：自然语言与模板操作，生成表格、图表、可视图及交互研究页。
- IP发展跟踪、主动发现可合作品牌最重要；智能营销情报仍独立存在。
- 销售支持完整覆盖品牌适配、卖点假设、多服务切入、双方商务线索、联系方式和跟进协作。
- 服务范围涵盖百度营销方案、数字人、云服务、整合营销；具体能力与案例待提供。
- 信息要求最新可得并可核验；支持持续关注IP及营销主题。
- 网页消息中心与如流双渠道推送；如流同时需要个人私信与团队群摘要。
- 支持分析报告导出；设计涵盖PDF、Word、Excel、PNG，PPT为后续候选。
- 所有功能通过同一研究项目、共享证据和版本衔接。
- Codex是开发工具；暂无现有应用链接，无优先数据平台。
- 本轮交付设计文档和Figma原型，未开发部署、未实际采集或发送消息。

## 开发前仍需确认
| 问题 | 用途 | 设计阶段处理 |

| 首批真实IP、品牌或营销主题，各提供2～3个 | 校验发展跟踪和品牌推荐是否实用 | 原型用明确标注的虚构样例 |
| 可用数据接口、数据产品或内部资料 | 确定来源覆盖与即时性 | 设计可替换来源层；导入仅为补充，不替代最终自动跟踪 |
| 如流企业应用权限、可用群及管理员 | 验证私信、群消息和身份绑定 | 两通道分别设计与验收 |

| 真实服务能力、案例及常见销售场景 | 保证商机和卖点建议不脱离业务 | 服务卡缺失时明确显示待补充 |
