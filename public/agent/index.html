Agent 接入

让你的助手检索消费品牌报道、读取热点榜，并在回答里附上原文。

Codex · 百度 DuMate · 腾讯 WorkBuddy

下载连接器

先安装 Node.js 22 或更高版本，在终端运行 node --version 确认版本。下载连接器并保存到固定文件夹。以下 Windows 示例使用 C:/CUE/cue-agent.mjs，macOS 和 Linux 用户请换成自己的绝对路径。CUE 的公开数据可免费读取，无需 API Key。

下载 CUE 连接器
  • search_articles 联网检索公开新闻和出版方报道
  • latest_articles 获取最新报道和原文
  • hot_events 查看热点走势与报道依据

Codex

  1. 在已安装 Codex CLI 的电脑上打开终端，将命令中的路径换成连接器的实际位置并运行。
codex mcp add cue -- node "C:/CUE/cue-agent.mjs"
  1. 运行 codex mcp get cue 核对启动命令和路径。桌面版与 CLI 使用同一配置目录时，重新打开 Codex 会话即可加载。
  2. 在新会话发送下面的测试问题。在 CLI 中也可以先输入 /mcp 查看工具列表。

百度 DuMate（百度搭子）

  1. 打开终端并运行下面的命令。看到本地地址后保持这个终端开启。
node "C:/CUE/cue-agent.mjs" --http
  1. 打开桌面版的「专家套件 · 技能」，选择「连接应用」，依次点击「添加」「添加应用」，选择手动配置。
  2. 应用名称填 CUE 品牌资讯，传输协议选 Streamable HTTP，服务端点填下方地址，请求头留空。
http://127.0.0.1:48173/mcp
  1. 保存并启用应用，在同一台电脑的新对话里选择 CUE，发送测试问题。重新开机后先运行上面的启动命令。

腾讯 WorkBuddy

  1. 打开「专家 · 技能 · 连接器」，进入「连接器」，点击「自定义连接器」，再点击「添加 MCP」。
  2. 在编辑器里填入下方 JSON，将 args 的路径换成实际文件位置。已有连接器时，只需把 cue 条目合并到现有 mcpServers 中。


  1. 保存，按客户端提示确认信任并启用 CUE。WorkBuddy 会自行启动 Node 进程。
  2. 打开 CUE 的工具列表，确认能看到三个工具，再在新对话中发送测试问题。

测试连接
请调用 CUE 的 hot_events 读取三个消费营销趋势，列出各自的案例和原文链接。


再试一次主题检索，例如“请调用 search_articles 搜索香水联名，按日期列出案例，合并转载”。连接成功时，会话里可以看到工具调用和带网址的结果。


没有看到工具或连接失败
若提示找不到 node，Windows 可运行 where.exe node，macOS 或 Linux 可运行 command -v node，将查到的绝对路径填进启动命令。若找不到脚本，请确认文件仍在设置的路径，扩展名是 .mjs。DuMate 连接失败时，请检查终端是否开启、地址是否含 /mcp，以及客户端与连接器是否运行在同一台电脑上。能列出工具但无法读取新闻时，可点下方文章 JSON 检查网络。
